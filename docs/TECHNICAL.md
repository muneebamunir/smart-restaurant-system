# Technical Documentation
This document describes the technical description of the project.

## Tools

### Next.JS
we are using Next.JS because it support both frontend in React.JS and backend. It allows us to use both Server-side Rendering and Client-side Rendering. It can be host easily on vercel.

### MonogoDB
MongoDB is decided to use as it provides us a heirarchial data approach. Some properties to be used are like objects instead of a regular string or number.
